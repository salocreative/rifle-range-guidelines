# Rifle Range brand guidelines

The brand guidelines for Rifle Range, on the Hurdcott Estate, Wiltshire. Designed by Salo Creative.

Live at https://toby-felton.github.io/rifle-range-guidelines/

## What's here

- `index.html`: the guidelines site (Strategy, Voice, Identity, Website)
- `assets/guidelines/`: the PDF guidelines
- `assets/logo/`: the logo suite (every version and colour, SVG, PNG, JPG, PDF and EPS)
- `assets/icons/`: the heritage icon set
- `assets/devices/`: the vintage ribbon, taken from the label artwork
- `assets/fonts/`, `assets/favicon/`, `assets/email/`, `assets/website/`: fonts, favicons and photos used by the site

## House rules

- These guidelines are locked. Changes are signed off by Salo.
- The same guidance lives in Creative in the Loop (brand: Rifle Range) for work made with Claude.
- The site is kept out of search engines. Share the link directly.
